About Cool Gallery

Cool Gallery is a simple, clean photo showcase built for the BYU-Idaho WDD131 course. It displays a curated set of lifestyle images in a responsive grid layout.

Click any image to open it in the full-screen viewer. The gallery works on desktop and mobile.
